Quick Start #

Get the development environment running locally in three simple steps:

bash 
# 1. Install dependencies
npm install

# 2. Start local Vite development server
npm run dev

# 3. Open browser at http://localhost:5173/

Installation & NPM Scripts #

Standard scripts available in package.json:

Command Description
npm run dev Starts the Vite development server with Hot Module Replacement on port 5173.
npm run build Compiles and bundles the production-optimized files into the /dist folder.
npm run preview Locally serves the production bundle from /dist for pre-deployment QA.
npm run lint Executes ESLint against all components to ensure clean code standards.

Folder Structure #

Clean, modular project organization adhering to standard React conventions: 

verdant-luxury-real-estate/
├── public/                     # Static public assets & brand logos
│   ├── documentation/          # Complete offline HTML documentation
│   └── logo/                   # Brand logos (dark and light)
├── src/
│   ├── assets/                 # 100% Local bundled photography
│   │   ├── house/              # High-resolution property photos (1.jpg to 7.jpg)
│   │   └── user/               # Client avatars for testimonials (avatar-1 to 8)
│   ├── components/
│   │   ├── layout/             # Navbar1 and Footer1 components
│   │   ├── sections/           # Properties, Developments, Marquee, About
│   │   └── ui/                 # Accessible Button, Badge, Modal primitives
│   ├── context/                # ThemeContext (Dark/Light + RTL state)
│   ├── data/                   # Editable JSON content files & image mapper
│   ├── pages/                  # Hero1, Hero2, 404, 500, and Auth Suite
│   │   └── auth/               # Login, Register, Forgot, Verify, Confirm
│   ├── routes/                 # AppRoutes configuration
│   ├── App.jsx                 # Lenis smooth scroll & Router wrapper
│   └── main.jsx                # Application entry point
├── package.json
└── vite.config.js

Pages & Routes Matrix #

All registered routes configured in src/routes/approutes.jsx:

100% Offline Local Photography #

To ensure zero dead external URLs or CDN loading issues, all high-resolution imagery is bundled locally and safely mapped through src/data/houseimages.js:

💡

Offline Guarantee: To add your own property photos, simply copy your JPG or PNG images into src/assets/house/ and reference them in propertiesdata.json by file name (e.g., "1.jpg").

Content Customization Guide #

Customize all website text, properties, contact details, and navigation links by editing the JSON files in src/data/ without writing React code:

  • navbardata.json: Brand name, phone number, CTA button text, and top links.
  • footerdata.json: Address, email, phone, office hours, and copyright disclaimer.
  • propertiesdata.json: Estate listings, prices, square footage, beds, and baths.
  • developmentsdata.json: Landmark architectural projects and factsheets.
  • testimonialsdata.json: Verified investor reviews and portfolio ratings.

Dark / Light Mode & RTL Support #

Controlled globally via ThemeContext:

🌓

Instant Theme Switcher

Toggles the .dark class on <html> with instant localStorage persistence.

🌍

RTL Layout Direction

Toggles dir="rtl" attribute on <html>, seamlessly adapting layout for Arabic and Hebrew.

Frequently Asked Questions #

Can I deploy this to Vercel, Netlify, or Apache?

Yes! Run npm run build and upload the generated /dist folder. For SPA routing on static hosts, rewrite all requests to /index.html.

How do I change the default theme to Light Mode?

In src/context/themecontext.jsx, change the default state fallback from "dark" to "light".
